# AI Tutor backend

Requires Node.js 22.5 or newer. For local development, copy `.env.example` to `.env`, set a random `JWT_SECRET` with at least 32 characters and a server-side `OPENAI_API_KEY`, then run `npm ci` and `npm start` from this directory. The API accepts the Android WebView's `null` origin and any origins listed in `ALLOWED_ORIGINS`.

Deploy behind HTTPS as one service instance. The SQLite database path is configurable with `DATABASE_PATH`. User accounts are password-hashed and signed bearer tokens scope captions, lectures, and conversation history to each account. `GET /api/auth/me` validates a restored app session; the app remembers the configured HTTPS server and learner email so a queued caption upload can resume after restart, and expired sessions require a fresh sign-in. On Android, the JWT is encrypted with an Android Keystore AES-GCM key, bound to its configured server URL, and exposed only to the tutor WebView; browser-only preview falls back to its local storage. The Android app disables backup so session data is not copied through Android backup. Configure a persistent database volume and backups. OpenAI credentials are read only from the backend environment and are never included in Android assets or build configuration.

Automatic lecture context accepts only cues already visible in a standard HTML5 captions/subtitles track during playback. The backend does not fetch course provider URLs, caption files, audio/video, or protected streams. Coverage is limited to played sections where the learner enabled official captions; visual analysis and transcription where captions are unavailable are unsupported. The app keeps unsent caption cues in a learner-scoped IndexedDB queue, retries after network/app recovery, and the backend idempotently merges timestamped batches for each learner/course/lesson. Captions remain marked as partial coverage.

Chat retrieves relevant cues from the full captured caption set and streams a teacher-style response. Follow-up question suggestions use the saved conversation and relevant caption excerpts. The study guide generates timestamp-checked chapters, concepts, definitions, formulas, revision notes, and practice questions using a broad sample of the captured cues; it reports how many cues were used. Summary, concept, flashcard, and quiz views render from this generated guide. Lecture detail responses include only the most recent 300 timestamped cues; the learner-scoped `/api/lectures/:id/segments` endpoint pages through older cues, while search and AI retrieval scan the complete stored set. Realtime voice uses server-issued temporary credentials, input speech transcription for saved conversation memory, semantic voice activity detection, interruption support, and the same partial caption context. OpenAI API keys stay in the backend environment.

## Production deployment

The included `Dockerfile` and `compose.yaml` run a non-root Node.js service with a persistent SQLite volume, read-only container filesystem, health check, HTTPS-front-proxy support, and required environment secrets. Install Docker Compose on a server with persistent disk and an HTTPS reverse proxy. In the backend directory, provide `JWT_SECRET` (at least 32 random characters), `OPENAI_API_KEY`, and optionally `ALLOWED_ORIGINS`, `OPENAI_TEXT_MODEL`, and `OPENAI_REALTIME_MODEL` to the host environment, then run `docker compose up --build -d`. Point the app's Tutor server field at the public HTTPS API base URL. Back up the mounted `tutor-data` volume. This repository does not deploy the service or supply these account secrets.

No supported official PW Skills developer interface for full lecture captions, transcript export, or visual analysis was found in the repository or public developer-facing material reviewed. The future integration boundary is `POST /api/lessons/captions`: a provider-authorized adapter can deliver verified caption segments there after its permission contract is confirmed. Until then, only already-visible HTML5 text-track cues are accepted; no protected stream or caption URL is fetched.
